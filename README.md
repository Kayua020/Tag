# ☀️ Projeto Página Web - Bom dia

Este é um projeto simples de uma página web estática desenvolvida em **HTML5**. A página exibe uma mensagem de "Bom dia", uma lista de tarefas/rotina diária, uma imagem do Sol com legenda e um botão para navegação.

---

## 📌 Demonstração e Estrutura do Código

O projeto conta com a seguinte estrutura de marcação:

- **Cabeçalho (`<header>`):** Título principal desejando "Bom dia".
- **Seção Informativa:** Exibição do dia da semana (`<h2>` e `<p>`).
- **Listas de Atividades (`<div class="materiais">`):**
  - Lista não ordenada (`<ul>`) com atividades básicas.
  - Lista ordenada (`<ol>`) detalhando o passo a passo da rotina matinal.
- **Mídia (`<img>` e `<figcaption>`):** Imagem ilustrativa do Sol acompanhada de uma legenda explicativa.
- **Navegação (`<a>` e `<button>`):** Botão interativo direcionando para outra página (`nãosei.html`).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação de todo o conteúdo e elementos da página.

## 🚀 Como Executar o Projeto

1. Clone ou baixe este repositório para o seu computador:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```
2. Navegue até a pasta do projeto.
3. Abra o arquivo `index.html` (ou o nome atribuído ao arquivo HTML) em qualquer navegador web de sua preferência (Google Chrome, Firefox, Edge, etc.).
